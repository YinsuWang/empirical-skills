# 典型经济学图形

选择能够回答本轮问题的图。使用matplotlib、Stata或R等精确绘图工具；不用AI图像生成绘制统计结果。保存绘图代码、tidy数据和正式PNG+PDF/SVG（环境可用时）。

| 图 | 必需内容 | 核查及解释 |
|---|---|---|
| 原始趋势 | 组名、年份、Y单位、各年样本N/支持、聚合/权重口径 | 原始/调整后区分；组间组成变化；不能称因果图 |
| Timing/cohort | 加入年份/强度、cohort数、never-treated、观察窗 | 日期来源与退出/重复处理；地图边界/缺失注明 |
| 事件研究 | 事件时间、估计目标、点估计、真实95%CI、零线、处理线、参考期 | 逐点/同时CI、聚合权重、尾部合并、支持变化、联合pretrend检验及定义 |
| RD | running variable、cutoff、分箱点与两侧拟合、带宽与局部估计注释 | 点的聚合不是估计；拟合不跨cutoff；操纵/离散支持另呈现 |
| First-stage/binscatter | X与Z、单位、样本、分箱和是否残差化 | 图不证明排除限制；趋势线不能替代正式第一阶段 |
| 稳健性系数图 | 设定标签、点估计、CI、零线/基准线、可比参数 | Y/尺度/参数不同分panel，不混成一条轴；全部预设/探索选择说明 |
| 异质性forest plot | 分组、效应、CI、N/支持、零线 | 单独给组间差异检验；显著性差异不等于异质性 |
| Placebo分布 | 模拟统计量、真实值、随机机制、seed/次数、尾部与经验p | 任意shuffle不是默认有效推断；标明分辨率 |
| 合成控制 | 实际/合成趋势、干预线、差距、donor/拟合信息 | placebo前拟合可比性，避免仅展示最好拟合 |

## 事件图细节

- 参考期是归一化零，显示特殊标记或注明，不画虚构置信区间。
- 缺少支持的事件期保持缺失，不补零；联合检验仅使用实际估计、非归一化的pre参数。
- 处理线位置按事件时间定义确定（0或-0.5等），表注明确，不机械套模板。
- 使用软件导出的区间；bootstrap、同时带、有限聚类t或弱IV区间不必等于±1.96SE。
- 报告预处理检验原假设、p、支持与功效；不能把“所有区间含0”称证明平行趋势。

## 通用版式与QA

- 使用简洁学术风格、可读字号、颜色/线型兼容黑白打印，不用装饰性渐变。
- 明确坐标单位、估计器、样本、聚类/推断、区间类型、必要图注；不要隐去跨零或反向结果。
- 按含义使用合理尺度，不用截断轴制造效应差异；长标签允许横向系数图或分panel。
- 单图避免过多系列，正文聚焦问题，附录给完整支持和结果。
- 实际打开导出图，检查区间是否裁切、图例和文字重叠、参考线正确、表图数字一致、所有点可追溯；修正后再交付。
