# 正文与独立论文审查报告的输出边界

## 作者负责的判断

- 以作者给定的制度背景、政策事实、识别来源和研究叙事为准，提供计算与组织支持。
- 不默认要求重建完整制度史、验证政策外生性叙事、制作制度事实图；不反复索要不影响本轮执行的信息。
- 直接影响编码/估计的关键口径有歧义时集中澄清；背景论证未充分展开但模型可执行时继续，待补事项写入审查报告。
- 不自行将时间、地域或强度差异称为已证实的外生来源。正文的参数与结果使用准确名称，证据充分性的审查另写。

## 图形由谁决定

DID研究在适用且数据支持时安排平行趋势/事件研究图；只做局部任务、缺乏必要期数或图不适用时，在审查报告记录原因。图中诊断评价与支持问题进审查报告，图是否入正文沿用作者任务约定。

其他研究以作者明确要求或既有方案为准。RD图、IV散点/残差图、原始趋势、地图、制度时间图、cohort图、机制示意图和forest plot都不设为必交。可以在审查报告提出具体图形建议，但不能先制作整套图，也不为图形选择反复打断可继续的分析。

## 内容归属

| 内容 | research_report.md：正文素材 | paper_review_report.md：独立审查 |
|---|---|---|
| 作者给定的制度背景/设计 | 按任务需要简洁使用 | 尚需作者补充的判断与材料 |
| 数据、变量、样本及模型 | 交代实证解释所需定义与实际口径 | 合并/缺失/异常/样本核验过程与疑点 |
| 系数、标准误、显著性、模型统计 | 正确报告，按汇报skill制表 | 数字溯源、计算核验、表图一致性 |
| 平行趋势、稳健性、机制等 | 作者指定入文的设计与真实结果 | 审查过程、诊断判定、额外未指定检验与解释限制 |
| 未执行或失败的模型 | 不机械罗列；不写成已完成 | 逐项记录原因、影响与后续动作 |
| 运行日志、spec_id、版本/seed | 不以工作清单形式入文 | 保留定位与可复现状态 |
| 论文证据安排表 | 不进入正文 | 集中记录章节/问题、表图、证据状态与缺口 |
| 经济量级 | 按真实参数客观换算与解释 | 核算依据、误差、外推与福利假设的检查 |
| 边界条件与政策含义 | 仅使用作者提供或明确要求入文的讨论 | 默认承接外推边界、成本、实施条件、政策建议及其证据 |
| “已审查/已核验/待确认”等 | 不出现工作过程评论 | 明确审查发现和待办事项 |
| “还不能据此得出结论”等 | 不自动添加防御性段落 | 记录具体问题、理由及可操作修正 |

## 正文表达

写出模型在什么样本估计、参数是多少、统计证据如何、对应多少实际单位。直接描述正式结果，不附逐项自我审核口吻。

示例（占位，不是实证结果）：

> 表X报告[模型]的估计。[首选列]中，[核心参数]为[数值]，标准误为[数值]，对应[实际量级]。加入[控制]后，点估计由[数值]变为[数值]。

若未识别为因果效应，使用准确的“系数/条件关联”等参数表述，不将审查意见从正文移走后改用无依据的因果断言。不因分开输出而隐瞒或改写已实施的正式分析结果。

## 审查表达

写“发现—证据—影响—建议”，注明涉及的spec_id、输出位置和由谁决定。将保守判断具体化，例如指出哪项识别证据不足、样本变化多少、应补什么信息；不只堆叠泛泛的风险句。

论文证据安排表仅用于作者内部规划，不要求固定九节、不预设每节必须有图，也不把制度背景和政策含义的作者工作设为程序运行门槛。

## 交付和适用范围

完整一轮分别生成两个文件；短任务只更新相关正文片段和已有审查报告的对应部分，不强制生成空章节。没有结果的纯规划任务只提供内部计划/审查意见，不虚构正文结果。用户专门询问识别问题或审查情况时可直接在对话回答，但仍不把该回答默认混入论文正文。
